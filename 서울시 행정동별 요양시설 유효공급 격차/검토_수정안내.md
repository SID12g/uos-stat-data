# 대회 보고서 검토 수정

2024년 자료의 주 계산은 유지하면서 지표의 뜻과 정책 해석을 정정했다. 수요는 실제 입소 대기자 수가 아닌 **65세 이상 1~2등급 잠재 중증 돌봄 지표**다. 수요 A는 연령 구조 표준화를 위한 선택이며 주소 이동 교정이 입증된 것으로 설명하지 않는다. 시설급여는 1~2등급뿐 아니라 일정 요건의 3~5등급도 가능하다([공단 고시 제2조](https://www.nhis.or.kr/lm/lmxsrv/law/lawFullContent.do?MODE=threeView&SEQ=1637)).

## 다시 계산하는 방법

분석 폴더에서 다음을 실행한다. 독립 점검에 필요한 의존성은 `requirements-review.txt`에 적었다. 전체 노트북을 실행하는 데 필요한 기존 환경을 대체하는 목록은 아니다.

```sh
python -m pip install -r requirements-review.txt
python 보고서_핵심_만들기.py
```

보고서 생성기는 검토 재계산을 먼저 실행한다. 공간 접근성은 저장된 수요·공급 좌표로 다시 계산하고 보존 성질 및 기존 CSV와의 일치를 확인한다. 기존 회귀·미래 CSV는 읽어서 요약하며, 회귀나 인구 예측 전체를 다시 적합했다고 주장하지 않는다. 노트북 보고서 문장은 `outputs/검토_재계산.json`과 입력·방법 코드의 SHA-256이 일치할 때만 표시한다. 입력이 달라졌으면 `python 검토_재계산.py`를 먼저 실행해야 한다. 바뀐 빈자리 계산 칸의 오래된 출력은 삭제했으며 종합 보고서 문장 칸만 새로 실행했다.

`outputs/우선동_가정민감도.csv`와 동 명단, `최소시설_최적화비교.csv`와 두 배치 파일, `빈자리_정의별_재계산.csv`, `검토_재계산.json`에 수치·조건·최적성 증명 하한·입력 해시를 기록했다. 최적해의 위치 조합은 여러 개일 수 있다. 기존 26곳 지도는 기존 순차 배치를 그대로 표시하며 정수 최적화 배치 파일과 동일한 위치 조합이라고 주장하지 않는다.

## 정책과 후속 검증

공공부지 제안은 확정 건설 물량보다 후보 검토로 제시한다. 후보별 소유권·용도지역·시설 연면적·사업비·운영비·인력과 도로 이동시간을 확인하고, 저소득·독거·이동 제약은 별도 형평 기준으로 결합한다. 23.6㎡/석은 시설 연면적 기준이며 토지 면적이 아니다. 재가서비스의 입소 대체 효과와 비급여 제도의 비용·보조금·이용 포기 위험은 아직 추정하지 않았다.

서울 동 순위는 만실 자료로 뚜렷하게 검증되지 않았다. 높은 만실 비율이 검정력을 제한할 가능성과 검증 실패의 원인 확인을 구별한다. 직선거리를 도로 거리로 바꾸면 시설 기여와 경쟁 수요가 함께 바뀌므로 접근성 변화의 방향을 미리 단정하지 않는다. 미래 값은 2024년 인정률·공급 고정 시나리오이며 2019→2024 인구 역검증, 동별 순이동·정비사업, 2025년 서울 지역별 안정성, 실제 입소 출발지·대기자 검증은 후속 과제로 남겼다.
